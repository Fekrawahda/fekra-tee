catalog.json preview

          

          

          
How publishing works: change things here, press Download catalog.json, upload it to the root of your GitHub repository (replace the old one) and commit. The storefront reads it on every visit, so it goes live as soon as GitHub Pages finishes publishing. This page holds no GitHub token and cannot publish by itself.

          
About the password: it keeps casual visitors out of this page, but the page and catalog.json are public files, so it is not bank-grade security. Use a long password. Your orders are protected separately by the Apps Script admin key.
